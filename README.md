# Task 2 – Network Security and Scanning

## ApexPlanet Cybersecurity & Ethical Hacking Internship

This repository contains the practical work completed for Task 2 of the ApexPlanet Cybersecurity & Ethical Hacking Internship.

## Objectives

- Perform passive reconnaissance
- Perform active reconnaissance
- Conduct TCP and UDP port scanning using Nmap
- Perform service and version detection
- Perform operating system detection
- Conduct vulnerability assessment using Nessus Essentials
- Analyze vulnerability findings
- Capture and analyze network traffic using Wireshark
- Demonstrate basic firewall rules using iptables
- Document scan results and security findings
